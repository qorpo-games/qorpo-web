How this works

An hourly job reads the studio's GitHub repositories (AneeMate web, backend and Unreal project, One Life, the Tamitos Move app, tamitos.com and TAMITOS Kids), counts commits and lines, and writes feed.json. This page and the popup on every page read that file. Lines count code and text; Unreal binaries, models and maps are not counted, so the real number is higher. All time numbers are a snapshot of every studio repository since 2021.

Why we publish it

Because "we are building" is the cheapest sentence in crypto. One token sits behind every game we ship, so the people who hold it deserve to see the shipping. If the feed goes quiet, you will know before we tell you.
